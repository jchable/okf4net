### Title: Add a minimal worked-example OKF bundle newcomers can run the CLI against
**Labels:** good first issue ; documentation
**Difficulty / est. effort:** ~1h, small

**Context:** The only bundle in the repo today is `tests/fixtures/appendix_a` (a byte-exact golden fixture — see "Never touch `tests/fixtures/`" in `CONTRIBUTING.md`), so a newcomer who wants to `okf validate`/`okf info`/`okf graph` something has nothing safe to point the CLI at without first authoring their own concept files by hand. A small, throwaway-friendly example bundle under `examples/` gives newcomers (and the README) something concrete to run the CLI against in one sitting.
**Files to touch:** `examples/quickstart/index.md` (new), `examples/quickstart/orders.md` (new), `examples/quickstart/refunds.md` (new), `README.md`
**What to do:**
1. Create `examples/quickstart/` with 2-3 tiny concept documents, e.g. `orders.md` and `refunds.md`, each with a valid frontmatter block (`type`, `title`, `description`, `timestamp` — see `Frontmatter.RequiredKeys` in `src/OKF4net/Frontmatter.cs` for the producer-side required keys) and a one-paragraph body; have `refunds.md` cross-link to `orders.md` via a relative markdown link (e.g. `[orders](./orders.md)`) to demonstrate §5 cross-linking.
2. Do not hand-write `index.md` — instead generate it with the CLI itself once the concept files exist: `dotnet run --project src/OKF4net.Cli -- index examples/quickstart` (or run the published `okf` binary). This also doubles as a smoke test that the example bundle is well-formed.
3. In `README.md`, add a short pointer to the new example directory near the `### As a CLI` section (or the top-of-file contributor callout), e.g. "Try it: `okf validate examples/quickstart`".
**How to verify:** `dotnet run --project src/OKF4net.Cli -- validate examples/quickstart` — expect exit code 0 and `✓ conformant with OKF v0.1` printed. Also run `dotnet run --project src/OKF4net.Cli -- info examples/quickstart` and confirm it reports the expected concept count.
**Good to know:** See the README's `## What OKF is` section for the concept/bundle/frontmatter vocabulary, and `## Mapping to the spec` for the §-by-§ table. Keep frontmatter values simple and realistic — this bundle is illustrative, not a fixture, so it is fine (and expected) to hand-edit later. Related: `add-agents-quickstart-sample.md` creates a separate agents-focused demo bundle under `samples/AgentsQuickstart/bundle/`; keep the two demo bundles distinct (this one is a plain library/CLI quickstart under `examples/quickstart/`) so they don't overlap.
