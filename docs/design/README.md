# Design documents

Historical design and planning documents for OKF4net, kept for context on how
and why the codebase is shaped the way it is.

- [`specs/`](specs/) — design specifications (requirements, architecture,
  decisions) written before implementation.
- [`plans/`](plans/) — step-by-step implementation plans derived from the
  specs, used to drive the actual porting work.

> **Historical record.** These documents describe the one-time migration that
> produced OKF4net. OKF4net is now an **independent .NET implementation** of
> the OKF spec and no longer tracks any other implementation. The documents
> below are snapshots of the plan at the time of writing and mention the
> original migration source only as history — the source code and
> [`README`](../../README.md) are the authoritative reference for current
> behaviour.
