# Design — Montée d'OKF4net vers la spec OKF v0.2

- **Date** : 2026-07-27
- **Branche** : `okf4net-okf0.2-support` (worktree, basée sur `dev`)
- **Statut** : design validé, en attente de relecture avant plan d'implémentation
- **Contexte amont** : [`docs/design/okf-python-vs-okf4net.md`](../../design/okf-python-vs-okf4net.md)
- **Spec de référence** : OKF v0.2 — [`GoogleCloudPlatform/knowledge-catalog/okf/SPEC.md`](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)

## 1. Objectif et positionnement

OKF4net cible aujourd'hui **OKF v0.1** (`OkfSpec.Version = "0.1"`). La spec upstream
est passée en **v0.2** : un sur-ensemble de v0.1 avec deux renommages breaking et
plusieurs familles de champs additifs. Ce design fait passer OKF4net à la
**conformité v0.2 comme unique cible**.

Principe directeur validé : **on se détache de la parité byte-exact avec l'ancien
binaire Rust** (Rust supprimé au commit `d20343c`, plus d'oracle vivant). Le
calquage Rust a servi à démarrer ; désormais OKF4net a sa propre implémentation,
alignée sur la **dernière** version de la spec. Aucune compatibilité v0.1
« pure » n'est maintenue — **sauf** les fallbacks que la spec v0.2 elle-même
sanctionne (§13), qui font partie intégrante de la conformité v0.2.

## 2. Périmètre

### Dans le périmètre (blocs A + B)

- **Provenance / confiance / cycle de vie (§5)** : `sources` (+ `usage_window`
  sibling, signaux `author`/`usage_count`/`last_modified`), `generated`,
  `verified`, `status`, `stale_after`, dérivation des **trust tiers** (§5.3).
- **Convention d'acteur (§7)** pour `generated.by` et `verified[].by`.
- **`okf_version`** dans l'`index.md` racine (§12).
- **Les deux renommages breaking (§13.1)** avec leurs fallbacks legacy
  sanctionnés par v0.2 :
  - `timestamp` → `generated.at` ; fallback : lire le `timestamp` legacy si
    `generated` absent (« MAY »).
  - body `# Citations` → frontmatter `sources` ; fallback : lire un `# Citations`
    legacy si `sources` absent (« SHOULD read sources, MAY still parse
    Citations »).

### Hors périmètre (différé, décision assumée)

- **Type `Attested Computation` (§10)** et ses clés `runtime`/`parameters`/
  `computation`/`executor`/`attester`/`receipt`.
- **Heading conventionnel `# Computation` (§4.2)**.
- **Navigation des champs path-valued en frontmatter (§6.2)** (suivre
  `computation`/`executor.resource`/`attester.resource`/`sources[].resource`
  bundle-path comme arêtes de graphe) — viendra avec §10.

Un bundle contenant un `Attested Computation` **se charge et se navigue** sans
erreur dès cette version (le `type` est une string libre, ses clés spéciales sont
des extensions non interprétées) ; on ne fait simplement pas encore de logique
dédiée.

## 3. Versionnage

| Élément | Avant | Après |
|---|---|---|
| Spec implémentée (`OkfSpec.Version`) | `"0.1"` | `"0.2"` |
| Version package OKF4net | `0.2.0` (publiée) | **`0.3.0`** |

Le bump du package à `0.3.0` et l'alignement éventuel de `CliVersion`
(`"0.1.0-alpha.1"`) relèvent de la **release** (skill `release`), pas de cette PR
de code. La version spec affichée par `okf -V` et la ligne `validate` bascule de
toute façon via `OkfSpec.Version`.

## 4. Journal des décisions (arbitrages validés)

1. **Sévérité des champs optionnels mal formés** → **Warning**. `Error` reste
   *strictement* §11 (frontmatter non-parseable, `type` manquant/vide, fichier
   réservé mal structuré → bascule `IsConformant` + exit 1). Un `generated` sans
   `by`, un `sources[]` sans `resource`, un `status` hors énum, un acteur mal
   formé n'invalident **pas** le bundle (§11 : « consumers MUST NOT reject »).
2. **Validation producteur** → `Validate()` recalibré à `[type, title,
   description]` (timestamp retiré). `ValidateConformance()` inchangé (type seul).
   `okf_write_concept` **auto-tampon­ne `generated`** (voir §6/§9).
3. **Péremption (`stale_after`)** → **signal, pas filtre**. Le validateur émet un
   Warning si `today >= stale_after` ; les consommateurs exposent un flag `stale`.
   La spec **ne prescrit rien** côté consommateur (§5.5 informatif). Le
   comportement est piloté par une **`StalePolicy`** configurable (décision 3bis).
3bis. **`StalePolicy`** à 3 modes dans le core : `Strict` (exclut) /
   `Tolerate(graceDays)` (tolère jusqu'à `stale_after + N` jours) / `Use`
   (inclut, flag exposé). **Défaut = `Use`** (permissif, jamais de drop
   silencieux).
4. **`usage_window`** → **sibling top-level** de `sources` (confirmé §5.1), pas
   par-entrée.
5. **`verified`** → un mapping seul est normalisé en liste 1 élément (§5.2).
6. **`# Citations` legacy** → conservé comme **fallback** de `document.Sources()`
   (v0.2-conforme). Priorité au champ `sources`.
7. **`okf_version` racine** → **silence si absente** (légal §12, cas courant) ;
   **Warning si déclarée et ≠ `"0.2"`** (best-effort, jamais de rejet, §12).
   `okf info` affiche la version déclarée si présente.
8. **Format d'acteur (§7)** → validation **stricte** : Warning si un `by` présent
   ne matche exactement aucune des 3 formes — `human:<id>` (id non-vide),
   `process:<id>` (id non-vide), `<producer>/<version>` (≥1 `/`, aucun côté vide).
9. **Champs recommandés (§4.1)** → `[title, description, resource, tags]`
   (fidélité spec pleine ; timestamp retiré).
10. **Sévérités legacy** → **Warning** pour usage du `# Citations` legacy (nudge
    de restructuration) ; **Info** pour usage du `timestamp` legacy (simple
    renommage). Révisables.
11. **Horloge** → modèle pur (`IsStale(asOf)` prend la date en paramètre) ;
    abstraction `IOkfClock`/`SystemClock` injectée uniquement là où « maintenant »
    est requis (validateur, politique consommateur). `Validate(bundle, IOkfClock?
    clock = null)` fournit `SystemClock` par défaut.

## 5. Architecture — Approche A (accesseurs typés paresseux)

`Frontmatter` reste l'enveloppe fine order-preserving sur `YamlMapping` (préserve
ordre + clés inconnues + round-trip). On ajoute des **projections paresseuses et
tolérantes** vers de petits value types en lecture seule, **jamais bloquantes**
(un champ mal formé n'arrête pas le chargement §3 ; tout jugement est reporté au
validateur). Zéro dépendance.

### Nouveaux value types (`src/OKF4net/`, `readonly record struct`)

**`Actor.cs`** (§7)
```
readonly record struct Actor(string Raw, ActorKind Kind, string? Id, string? Producer, string? Version)
enum ActorKind { Human, Process, Producer }
Actor Parse(string raw):
  "human:<id>"   (id non-vide)                → Human
  "process:<id>" (id non-vide)                → Process
  "<a>/<b>"      (≥1 '/', 2 côtés non-vides)  → Producer(a, b)
  sinon                                        → Producer, IsWellFormed=false
bool IsHuman        => Kind == Human
bool IsWellFormed   // matche une des 3 formes exactes (pilote le Warning strict)
```

**`Trust.cs`** (§5.2 / §5.3)
```
readonly record struct Stamp(Actor By, string? At)      // 'at' ISO-8601 optionnel
enum TrustTier { Unverified, MachineConfirmed, HumanReviewed }
// projections :
Stamp? Generated                    // {by*, at} ; 'by' requis DANS l'objet (sinon warning)
IReadOnlyList<Stamp> Verified       // liste OU mapping seul → liste 1 élément
TrustTier Tier =>
   Verified vide            → Unverified
   au moins un By.IsHuman   → HumanReviewed
   sinon                    → MachineConfirmed
```

**`Provenance.cs`** (§5.1)
```
readonly record struct Source(string? Id, string Resource, string? Title,
                              Actor? Author, long? UsageCount, string? LastModified)
readonly record struct UsageWindow(string? From, string? To)
// resource requis DANS l'entrée : absent → Resource="" + warning, entrée exposée quand même
IReadOnlyList<Source> Sources
UsageWindow? UsageWindow            // sibling top-level de sources
```

**`Lifecycle.cs`** (§5.4 / §5.5)
```
enum ConceptStatus { Draft, Stable, Deprecated }
ConceptStatus Status                // absent ⇒ Stable ; valeur inconnue ⇒ Stable + warning (via raw)
string? StaleAfter                  // date brute YYYY-MM-DD
bool IsStale(DateOnly asOf) => StaleAfter parseable && asOf >= date
```

**`StalePolicy.cs`** (décision 3bis, dans le core car partagé Agents + Catalog)
```
enum StaleMode { Strict, Tolerate, Use }
readonly record struct StalePolicy(StaleMode Mode, int GraceDays)
  static Use (défaut) / Strict / Tolerate(days)
  bool Admits(Lifecycle lc, DateOnly today)   // logique unique testable en core
```

**`IOkfClock` / `SystemClock`** (`src/OKF4net/`) : `DateOnly Today`. `SystemClock`
= horloge réelle ; `FixedClock` côté tests.

## 6. Intégration `Frontmatter` / `OkfDocument`

**`Frontmatter.cs`**
- `KnownKeys` étendu : `type, title, description, resource, tags, timestamp`
  *(legacy reconnu)* `, generated, verified, sources, usage_window, status,
  stale_after`.
- `RequiredKeys` → `[type, title, description]`.
- Getters paresseux : `Sources`, `UsageWindow`, `Generated`, `Verified`,
  `TrustTier`, `Status`, `StaleAfter`, `IsStale(asOf)`.
- `Timestamp` (brut) **conservé** = lecteur legacy. Ajout `GeneratedAt =
  Generated?.At` et **`LastChangedAt = GeneratedAt ?? Timestamp`** (fallback §13).

**`OkfDocument.cs`**
- **`Sources()`** (croise frontmatter + body) : `Frontmatter.Sources` si non-vide
  → sinon fallback `# Citations` mappé en `Source`. Sémantique consommateur v0.2
  complète (le fallback est v0.2-conforme, pas un « mode v0.1 »).
- `Citations()` / `LinkScanner.ExtractCitations` **conservés** (alimentent le
  fallback).
- `Validate()` → nouveau `RequiredKeys`. `ValidateConformance()` inchangé.
- `Serialize()` **inchangé** (order-preserving) → golden `fmt` byte-identique.

Distinction d'API : `document.Sources()` = « consommateur v0.2 tolérant, toutes
les sources quelle que soit leur forme » ; `frontmatter.Sources` = « lecture
stricte du champ `sources:` littéral ». Les deux sont v0.2-conformes.

## 7. Validateur (`BundleValidator`)

Signature : `Validate(Bundle bundle, IOkfClock? clock = null)`. Sévérité `Error`
inchangée (§11 uniquement). Nouveaux diagnostics :

| Déclencheur | Sévérité | Message (esprit) |
|---|---|---|
| champ recommandé manquant : `title`/`description`/`resource`/`tags` | Warning | missing recommended frontmatter field `X` |
| `generated` présent sans `by` | Warning | generated missing required `by` |
| `generated.at` non-ISO | Warning | generated.at is not ISO-8601 |
| acteur (`generated.by`/`verified[].by`) mal formé (strict §7) | Warning | actor does not match §7 form: `…` |
| `verified[]` entrée sans `by` / `at` non-ISO | Warning | verified entry missing `by` / not ISO-8601 |
| `sources[]` entrée sans `resource` | Warning | source entry missing required `resource` |
| `usage_window` `from`/`to` non-date | Warning | usage_window bounds not ISO date |
| `status` hors {draft,stable,deprecated} | Warning | unknown status `…` (treated as stable) |
| `stale_after` non-date | Warning | stale_after is not `YYYY-MM-DD` |
| `stale_after` valide **et** `clock.Today >= stale_after` | Warning | concept is stale (stale_after `…`) |
| root `index.md` déclare `okf_version` ≠ `"0.2"` | Warning | declared okf_version `…` unsupported (best-effort) |
| `document.Sources()` a fallback sur `# Citations` legacy | Warning | using legacy `# Citations`; migrate to `sources` |
| `generated` absent, `timestamp` legacy utilisé | Info | using legacy `timestamp`; prefer `generated.at` |

`okf_version` absente → **aucun diagnostic**. Le check existant (« root index.md
frontmatter should declare only okf_version ») est conservé/aligné §12.

## 8. CLI et goldens

- `OkfSpec.Version = "0.2"` → `okf -V` = `okf <version> (OKF spec v0.2)` ; ligne
  `validate` = `✓ conformant with OKF v0.2`.
- `okf info` : ligne `okf_version: <x>` **uniquement si** la racine en déclare une.
- `okf parse` : inchangé (pas de golden ; enrichissement futur).
- `index`/`graph`/`fmt` : logique inchangée.

**Impact goldens — un seul fichier change :**

| Golden | Sort | Raison |
|---|---|---|
| `validate.out` | **régénéré** (oracle v0.2 maison) | version v0.1→v0.2 ; warning `timestamp` disparaît ; `appendix_a` (legacy `timestamp`) → Info « using legacy timestamp » ; warnings `resource`/`tags` si absents |
| `validate.exitcode` | inchangé (0) | `appendix_a` reste conformant (tout le neuf est Warning/Info) |
| `info.out` | inchangé | pas d'index racine dans `appendix_a` → pas de ligne `okf_version` |
| `graph.dot` | inchangé | graphe = liens du body seulement |
| `fmt/users.md` | inchangé | `Serialize()` order-preserving |
| `index-input/**` | inchangé | génération d'index insensible aux champs v0.2 |

**Fixtures** : la fixture d'entrée `appendix_a` **n'est pas modifiée** — gardée en
forme v0.1 (avec `timestamp`) comme test de digestion legacy par un consommateur
v0.2. Distinction nette : *inputs intacts* / *oracle de sortie régénéré*.

**Procédure de régénération de `validate.out`** : après implémentation, lancer
`okf validate tests/fixtures/appendix_a` en in-process, capturer la sortie, la
**relire ligne à ligne** pour valider chaque diagnostic, l'enregistrer comme
nouvel oracle. Légitime car détachement assumé de la parité Rust.

## 9. Couche consommateur

**Core partagé** : `StalePolicy`, `IOkfClock`/`SystemClock` vivent dans
`OKF4net` (ancêtre commun d'Agents et Catalog).

**`OKF4net.Agents`**
- `okf_write_concept` : **auto-stamp `generated`** = `{ by: "okf4net/<version>",
  at: <now UTC ISO-8601> }` à chaque écriture (rafraîchit `at`), si non fourni par
  l'appelant. Acteur producteur configurable via options. `Validate()` producteur
  = `[type,title,description]`. (Le trust tier dérive de `verified`, pas de
  `generated` — aucune fausse confiance fabriquée.)
- `okf_append_log` : passe à l'horloge injectée.
- `OkfContextProvider` : `StalePolicy` dans `OkfContextProviderOptions` (défaut
  `Use`) ; annote `stale`/`status`/`trust` dans le bloc `<okf-context>`.
- **Exposition outils** : `okf_read_concept` ajoute une **ligne méta compacte**
  (`status: … | trust: … | stale: …`) quand pertinent ; `okf_search` marque les
  résultats stale/deprecated d'un tag court.

**`OKF4net.Catalog`**
- `StalePolicy` sur `KnowledgeQuery`/`KnowledgeCatalogOptions` ; appliquée par
  `DefaultKnowledgeResolver`.
- `KnowledgePassage`/`KnowledgeSearchResult` portent `TrustTier`, `Status`,
  `IsStale` (signal exposé au host).
- `IOkfClock` injecté ; DI Hosting enregistre `SystemClock` (override possible).

## 11. Contraintes projet respectées

- **Zéro dépendance** au cœur : tous les nouveaux types sont BCL-only.
- **Chargement permissif §3** : les projections ne throwent jamais ; tout jugement
  passe par le validateur.
- **File-scoped namespaces, nullable, XML doc sur API publique, SPDX header**
  (`LGPL-3.0-or-later`) sur les nouveaux fichiers.
- **`dotnet format`** clean ; warnings = erreurs.
