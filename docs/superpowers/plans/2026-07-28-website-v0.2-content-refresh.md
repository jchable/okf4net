# Website v0.2/Agents/Catalog Content Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring `web/` (the public site, `jchable.github.io/okf4net`) up to date with the project's actual
`dev` state — OKF spec v0.2, the shipped `OKF4net.Agents` package, and the shipped
`OKF4net.Catalog`/`OKF4net.Catalog.Hosting` packages, none of which the site currently reflects.

**Architecture:** The site is itself modeled as an OKF bundle — each page is a "concept" built from shared
`web/src/components/doc/` primitives (`PageDoc`, `Chapter`, `MapTable`, `ConceptGrid`, `Steps`, `Tag`,
`Next`, `Warn`). Five phases, in dependency order: (1) mechanical v0.1→v0.2 rebrand, (2) new `/docs/agents`
reference page, (3) new `/docs/catalog` reference page, (4) `/docs/spec` table rebuilt against the verified
v0.2 section numbering, (5) final consistency pass.

**Tech Stack:** Vite + React 19 + `vite-react-ssg` (static site generation) + `react-router-dom`, TypeScript,
Vitest (`jsdom`) for component tests. Zero new npm dependencies — everything is built from the existing
`web/src/components/doc/` primitives.

## Global Constraints

- **Zero new dependencies.** `web/package.json` already has everything needed (`react`, `react-dom`,
  `react-router-dom`, `vite-react-ssg`); do not add packages.
- **`CliVersion = "0.1.0-alpha.1"` never changes** (`src/OKF4net.Cli/OkfCli.cs:19`) — only the *spec*
  version string (`OKF spec v0.1` → `v0.2`, `conformant with OKF v0.1` → `v0.2`) is wrong on the site.
- **Every technical claim must trace to verified code**, not to a README recopied uncritically — the audit
  in `docs/superpowers/specs/2026-07-28-website-v0.2-content-refresh-design.md` (§0 spec ToC, addendum API
  inventory) is the source of truth for this plan; all facts below were re-derived from it.
- **Follow existing page patterns exactly.** New pages are built only from `web/src/components/doc/`
  exports (`PageDoc`, `Chapter`, `MapTable`, `ConceptGrid`/`Cell`/`Term`, `Steps`, `Tag`, `Next`, `Warn`) —
  do not introduce new one-off markup or new shared components.
- **After every task:** `npm --prefix web run typecheck` (`tsc -b`) and `npm --prefix web test` (vitest)
  must both pass clean.
- **SPDX header** `// SPDX-License-Identifier: LGPL-3.0-or-later` on every new/touched file (all touched
  files already have it — new files must too).
- **Commit after every task**, following the existing repo commit style (`type(scope): summary`).
