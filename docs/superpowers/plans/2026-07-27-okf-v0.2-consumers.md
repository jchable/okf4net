# OKF v0.2 — Consumer Layer (Agents + Catalog) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the v0.2 core types into the consumer layers: `okf_write_concept` auto-stamps `generated`; `okf_read_concept`/`okf_search` surface a compact v0.2 metadata signal; and both `OkfContextProvider` and the `OKF4net.Catalog` resolver honour a configurable `StalePolicy` and carry trust/status through to consumers.

**Architecture:** Reuses the core value types from **Plan 1** (`Actor`, `Stamp`, `TrustTier`, `Lifecycle`, `StalePolicy`, `IOkfClock`). Staleness is a signal, not a silent filter: the default policy (`StalePolicy.Use`) surfaces everything and only annotates; `Strict`/`Tolerate` opt into exclusion. Auto-stamping is scoped to the Agents write path via an opt-in flag on the shared `BundleConceptWriter`, so Catalog memory writes are unaffected.

**Tech Stack:** C# / net10.0, xunit. `OKF4net.Agents` → `Microsoft.Agents.AI` only; `OKF4net.Catalog` → `OKF4net` only; `OKF4net.Catalog.Hosting` → `Microsoft.Extensions.DependencyInjection.Abstractions` only.

```csharp
    private string MaybeStampGenerated(string frontmatterYaml)
    {
        if (!AutoStampGenerated)
        {
            return frontmatterYaml;
        }

        YamlValue parsed;
        try
        {
            parsed = YamlValue.Parse(frontmatterYaml);
        }
        catch (Yaml.YamlParseException)
        {
            return frontmatterYaml; // let BuildValidatedContent surface the parse error unchanged
        }

        if (parsed is not YamlMapping map || map.ContainsKey("generated"))
        {
            return frontmatterYaml;
        }

        var generated = new YamlMapping();
        generated.Insert("by", new YamlString(ProducerActor));
        generated.Insert("at", new YamlString(UtcNow().ToString("yyyy-MM-ddTHH:mm:ss", CultureInfo.InvariantCulture) + "Z"));
        map.Insert("generated", generated);
        return map.ToYamlString();
    }
```
