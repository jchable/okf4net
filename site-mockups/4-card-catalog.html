OKF stores knowledge as a directory of markdown files with YAML frontmatter. OKF4net is its zero-dependency .NET toolchain — a C# library and an okf CLI to parse, validate, index and graph every card in the drawer.

I.The format

What gets filed, and how

“If you can cat a file, you can read OKF; if you can git clone a repo, you can ship it.” The format is intentionally minimal:

bundle
A directory tree of UTF-8 markdown files — the unit of distribution.
concept
One document: YAML frontmatter between ---, then a markdown body.
concept id
The path with .md removed — tables/users.md → tables/users.
cross-links
Ordinary markdown links between concepts; backlinks are derived for you.
index.md · log.md
Reserved filenames: directory listings for progressive disclosure, and date-grouped change history.
conformance
One hard rule — a non-empty type per concept. Everything else is tolerated.
II.The library

Pull a drawer, read every card

Bundle.Load is permissive by design: it never aborts on a bad file, collects parse errors, and keeps broken links in the graph so you can find them. Frontmatter keeps its full ordered mapping — unknown keys survive round-trips byte for byte.

using OKF4net;

var bundle = Bundle.Load("./my_bundle");
Console.WriteLine($"{bundle.Count} concepts");

var report = BundleValidator.Validate(bundle);   // §9 conformance

var id = ConceptId.Parse("tables/orders");
foreach (var b in bundle.Backlinks(id))          // who cites this card?
    Console.WriteLine($"cited by {b}");

III.The okf CLI

Six commands, one AOT binary

Native AOT, self-contained, no .NET runtime needed on the target machine. okf validate exits non-zero on a non-conformant bundle — it drops straight into CI.

CommandDoes
okf validate <bundle>Check against OKF v0.1 conformance (§9)
okf info <bundle>Summarize — concepts, types, links, version
okf index <bundle>(Re)generate every index.md
okf graph <bundle>Print the cross-link graph (--dot for Graphviz)
okf parse <file>Parse one document, print its structure
okf fmt <file>Normalize by parse + re-serialize (-w writes)
$ okf validate ./bundles/ga4
OK: bundle is conformant with OKF v0.1 (42 concepts)
$ okf graph ./bundles/ga4 --dot | dot -Tsvg > graph.svg
IV.Contribute

File a card of your own

One prerequisite: the .NET SDK. Zero third-party runtime dependencies is a design rule — contributions keep it that way. The lending slip:

  • Fork, and branch from main.
  • Add or update tests — the suite is the contract, golden fixtures are byte-exact (never let a formatter touch tests/fixtures/).
  • dotnet test and dotnet format --verify-no-changes pass; warnings are errors.
  • Open a PR and cite the spec section (§) for any behavioural change.
