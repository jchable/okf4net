Open Knowledge Format · v0.1 · .NET

Every markdown file is a node.
Every link is an edge.

OKF4net loads a directory of markdown files and gives you the knowledge graph inside it — concepts, cross-links, backlinks, conformance. Zero third-party dependencies, pure C#.

dotnet add package OKF4net okf --help
bundle.Backlinks("tables/users") — hover the graph
§2–§3

A format you can cat

bundle/

A directory tree of UTF-8 markdown files — the unit of distribution. Ship it with git clone.

concept.md

YAML frontmatter between --- delimiters, then a markdown body. One file, one concept.

tables/users

A concept id is just the path minus .md. Links between files are ordinary markdown links.

index.md · log.md

Reserved names: generated directory listings for progressive disclosure, and date-grouped change history.

§4–§5

Load. Validate. Traverse.

Permissive by design. Bundle.Load never aborts on a bad concept file — parse failures are collected in ParseErrors and loading continues. Broken cross-links stay in the graph as edges to non-existent concepts, so you can find them.

  • Frontmatter preserves everything — a full ordered mapping with typed getters, so unknown producer keys survive round-trips.
  • Two validation levels — §9 conformance only, or the stricter producer-side check.
  • A documented YAML subset — block/flow collections, quoted scalars, |/> blocks; clear errors for the rest.
Program.csC#
using OKF4net;

var bundle = Bundle.Load("./my_bundle");
Console.WriteLine($"{bundle.Count} concepts");

// Conformance check (§9).
var report = BundleValidator.Validate(bundle);

// Walk the cross-link graph.
var id = ConceptId.Parse("tables/orders");
foreach (var link in bundle.LinksFrom(id))
    Console.WriteLine($"{id} -> {link.Target}");
foreach (var b in bundle.Backlinks(id))
    Console.WriteLine($"cited by {b}");
§6–§9

One AOT binary for CI

okf validate <bundle>Conformance check, non-zero exit on failure
okf info <bundle>Concepts, types, links, version
okf index <bundle>(Re)generate every index.md
okf graph <bundle>Cross-link graph, --dot for Graphviz
okf parse <file>Print one document's structure
okf fmt <file>Normalize by parse + re-serialize
ci.shnative AOT · no runtime required

OK: conformant with OKF v0.1 · 42 concepts
