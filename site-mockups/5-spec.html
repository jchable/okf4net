§2–§3

Bundles and concept ids

A bundle is a directory tree of UTF-8 markdown files — the unit of distribution. A concept is one file; its id is the path with .md removed, so tables/users.md becomes tables/users. Reserved filenames index.md and log.md carry directory listings and change history.

The format's whole bet: if you can cat a file, you can read OKF; if you can git clone a repo, you can ship it.

§4

Concept documents

YAML frontmatter between --- delimiters, then a markdown body. Frontmatter keeps the full ordered mapping with typed getters on top — producer-defined keys survive round-trips, byte for byte, as the spec requires.

var doc = OkfDocument.Parse("---\ntype: Metric\ntitle: DAU\n---\n\n# Body\n");
Console.WriteLine(doc.Frontmatter.Type);  // "Metric"
doc.ValidateConformance();                // throws on failure (§9)
var text = doc.Serialize();               // key order + body preserved

The YAML parser is a documented subset — block/flow collections, quoted and plain scalars, |/> blocks, comments — with clear errors for anchors, tags, and everything frontmatter never uses.

§5 + §8

Cross-links, backlinks, citations

Concepts link with ordinary markdown links, absolute or relative. Bundle.Load builds the whole graph — and never aborts on a bad file: parse failures land in ParseErrors, broken links stay in the graph as edges to missing concepts.

var id = ConceptId.Parse("tables/orders");
foreach (var link in bundle.LinksFrom(id))
    Console.WriteLine($"{id} -> {link.Target} (exists: {link.Exists})");
foreach (var b in bundle.Backlinks(id))
    Console.WriteLine($"cited by {b}");
§6–§7

Index and log generation

IndexGenerator (re)builds every index.md listing for progressive disclosure; ChangeLog parses and builds log.md update histories. Output is verified against golden fixtures — byte-exact, matching the reference implementation.

§9 + §11

Conformance, in CI

Conformance requires exactly one thing: a non-empty type on every concept. BundleValidator reports severity-tagged diagnostics; the CLI exits non-zero, so validation drops straight into CI.

$ okf validate ./bundles/ga4
OK: bundle is conformant with OKF v0.1 (42 concepts)
$ okf graph ./bundles/ga4 --dot | dot -Tsvg > graph.svg

Contribute a section

One prerequisite: the .NET SDK. Zero third-party runtime dependencies is a design rule — contributions keep it that way. Behavioural changes cite their spec § in the PR description.

  • Fork and branch from main.
  • Tests are the contract — including byte-exact golden comparisons; never reformat tests/fixtures/.
  • dotnet test and dotnet format --verify-no-changes pass; warnings are errors.

Ship knowledge as files.

Star the repo, open an issue, or pick a good first one. The spec is short, the codebase is dependency-free, and the test suite tells you immediately whether you're right.
